# 18. Abuse Protection

# 19. Persist-before-Handoff

Harte Reihenfolge:

1. validate
2. resolve allowlisted product
3. validate consent
4. persist order/request
5. create durable status/outbox
6. CRM/order routing
7. optional Mail/Internal Side Effects
8. final/retry state

Provider Failure darf keine Order vernichten.
