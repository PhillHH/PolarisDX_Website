# 0. Zweck und Rolle von AP14

AP14 macht aus der bestehenden IglooPro-Seite eine belastbare, eigenständige B2B-Produktstrecke. Das Paket ist bewusst produktzentriert: Es verbindet Positionierung, Produktvisualisierung, Features, Workflow, technische Spezifikationen, Claim-Konsistenz, Product Structured Data und eine reale Anfrage-/Secondary-Conversion-Strecke.

Der wichtigste harte Vertrag dieses Pakets ist die Konsistenz des beschlossenen Claims **`CV < 2 %`**. Dieser Wert ist eine gelockte Produkt-/Content-Entscheidung. Das Repository behauptet **keine unabhängige wissenschaftliche Validierung** dieses Claims. AP14 muss verhindern, dass alte `<5 %`-Aussagen, widersprüchliche Reader-Formulierungen oder stärkere Genauigkeits-/Garantiebehauptungen in irgendeinem produktiv erreichbaren Ausgabekanal verbleiben.

AP14 ist zugleich die letzte große Produktausarbeitung vor AP15. Es darf weder die Epigenetik-Säule noch die finale Lead-Magnet-/CRM-/Tracking-Plattform vorziehen.
